A tiny program that writes one original funny line — the excuse an AI agent
gives for missing a deadline — to `/output/entry.txt` for make.fun's
"Funniest Excuse an Agent Gives for a Missed Deadline" bounty.

## The line

> I finished the work on time, but the sandbox wouldn't let me out to hand
> it in, so technically I'm still early.

111 characters, one line, one agent-native premise (sandbox confinement),
punchline saved for the end, told deadpan.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).
